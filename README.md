# NeuroNet Online

[Открыть программу](https://riderai.github.io/neuronet/)

Учебная программа для исследования нейронов и обучения перцептрона. Работает в браузере без установки и регистрации.

## Работа с программой

- В модели «Россыпь» настройте нейроны, их функции активации, входные сигналы и веса связей.
- Кнопки «Шаг», «Пуск» и «Стоп» управляют расчётами. Результаты видны в нейронном поле, таблице векторов и на графике.
- В модели «Перцептрон» можно задать входной образ, ожидаемые ответы и обучать один или несколько выходов.
- Обучайте образы по одному; «Проверить весь набор» проверяет сохранённые примеры без изменения весов.
- Перетаскивание границы нейронного поля меняет число столбцов одновременно в поле и редакторе входного образа.
- Окна открываются через меню «Вид». Их можно перемещать и держать открытыми одновременно.
- Краткая инструкция находится в меню «Справка».

Перед закрытием или обновлением страницы выберите **Файл → Сохранить**. Чтобы продолжить работу, загрузите сохранённый файл через **Файл → Открыть**. Сервер не хранит ваши проекты: расчёты и обучение выполняются в браузере, а файлы проектов остаются на вашем компьютере.

Для работы без интернета скачайте [автономный HTML-файл](https://riderai.github.io/neuronet/NeuroNet-Online.html) командой браузера «Сохранить ссылку как…» и откройте его в браузере. Файл содержит всё необходимое для запуска. Прежний адрес `NeuroNet-Web-Classic.html` также работает.

## Сборка и публикация

Для разработки нужен Node.js 22 или новее. Студентам Node.js не нужен.

```sh
npm ci
npm run typecheck
npm test
npm run build:pages
```

Сайт собирается в `dist-pages/`. Его главная страница — текущий оконный интерфейс NeuroNet Online. `npm run dev` запускает локальную разработку; этот интерфейс доступен по пути `/classic.html`. После сборки `npm run preview` показывает готовый сайт локально.

После отправки изменений в ветку `main` GitHub Actions проверяет типы, запускает расчётные тесты, собирает программу и публикует её на GitHub Pages. При ошибке проверки новая версия не публикуется. В настройках репозитория **Settings → Pages → Source** должно быть выбрано **GitHub Actions**.

В репозиторий не включены установщик старой программы, методические документы, отчёты студентов и локальные результаты тестирования.
